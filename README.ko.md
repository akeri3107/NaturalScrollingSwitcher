# Natural Scrolling Switcher

[English](README.md)

Natural Scrolling Switcher(NSS)는 Mac에 연결된 포인팅 장치에 따라 macOS의 전역 **자연스러운 스크롤** 설정을 자동으로 관리하는 가벼운 메뉴 막대 유틸리티입니다.

다음과 같은 사용 환경을 원하는 사용자를 위해 만들어졌습니다.

- 트랙패드에서는 **자연스러운 스크롤**
- 외장 마우스에서는 **일반적인 스크롤**

마우스를 연결하거나 분리할 때마다 시스템 설정을 열어 스크롤 방향을 직접 변경하지 않아도 NSS가 자동으로 처리합니다.

---

## 주요 기능

- 연결된 외장 마우스 자동 감지
- macOS의 '자연스러운 스크롤' 설정 자동 전환
- 이벤트 기반의 장치 상태 감지
- 각 마우스별 자동 / 수동 모드 설정
- 각 마우스별 스크롤 방향 설정
- 마우스 재연결 시 저장된 설정 복원
- 여러 외장 마우스 지원
- 내장 장치(트랙패드) 표시 옵션
- 로그인 시 자동 실행 지원
- 한국어 및 영어 인터페이스
- macOS 메뉴 막대에서 간단하게 실행

---

## 작동 방식

macOS는 모든 마우스 및 트랙패드(이하 '포인팅 장치')에 대해 하나의 전역 스크롤 방향 설정을 사용합니다.

NSS는 연결된 포인팅 장치를 감지하고, 설정된 장치 정책에 따라 이 값을 자동으로 변경합니다.

내장 트랙패드와 외장 마우스를 함께 사용하는 일반적인 환경에서는 다음과 같이 동작합니다.

| 상황 | 스크롤 방식 |
| --- | --- |
| 트랙패드만 사용 | 자연스러운 스크롤 |
| 외장 마우스 연결 | 일반적인 스크롤 |
| 외장 마우스 연결 해제 | 자연스러운 스크롤 |

따라서 트랙패드와 일반 마우스를 번갈아 사용할 때마다 macOS 설정을 직접 바꿀 필요가 없습니다.

---

## 장치 설정

NSS 메뉴의 **장치...** 를 선택하면 연결된 포인팅 장치를 관리할 수 있습니다.

각 장치에는 **자동**과 **수동** 두 가지 모드를 설정할 수 있습니다.

### 자동

장치를 NSS의 자동 전환 동작에 맡깁니다.

일반적인 외장 마우스의 경우 마우스가 연결되면 NSS가 시스템을 일반적인 스크롤 방식으로 변경하고, 마우스가 연결 해제되면 다시 자연스러운 스크롤 방식으로 복원합니다.

### 수동

해당 장치에 적용할 스크롤 방향을 사용자가 직접 지정합니다.

수동 모드에서는 **스크롤 방향 설정**을 사용하여 원하는 스크롤 방식을 선택할 수 있습니다.

---

## 여러 장치를 연결한 경우

마우스가 여러 개 연결되어 있을 경우 NSS는 다음 우선순위에 따라 어떤 장치의 설정을 적용할지 결정합니다.

1. 가장 최근에 설정이 변경된 장치
2. 그다음으로 가장 최근에 연결된 장치

현재 적용 중인 마우스가 연결 해제되면 남아 있는 마우스 중 다음 우선순위에 해당하는 장치의 설정을 적용합니다.

macOS는 모든 포인팅 장치에 하나의 전역 스크롤 방향만 사용하기 때문에, 동시에 사용 중인 두 장치에 서로 다른 스크롤 방향을 각각 적용할 수는 없습니다.

---

## 장치 인식

NSS는 지원되는 포인팅 장치를 기억하며, 장치를 다시 연결했을 때 이전 설정을 복원하려고 시도합니다.

가능한 경우 시리얼 번호나 고유 장치 ID와 같이 비교적 안정적인 장치 정보를 사용하여 이전에 연결했던 장치를 식별합니다.

일부 장치는 제한된 식별 정보만 제공하기 때문에, 동일한 장치를 항상 확실하게 구분하지 못할 수도 있습니다.

## 메뉴 막대

NSS 메뉴에서는 다음 기능을 사용할 수 있습니다.

- **NSS에 대하여**
- **로그인 시 실행**
- **NSS 제어**
  - 활성화
  - 비활성화
- **언어(Language)**
  - 시스템 기본값
  - English
  - 한국어
- **장치...**
- **Natural Scrolling Switcher 종료**

### NSS 제어

**비활성화**를 선택하면 앱을 종료하지 않고 NSS의 자동 스크롤 방향 제어를 일시적으로 중지할 수 있습니다.

필요할 때 메뉴 막대에서 다시 **활성화**하면 됩니다.

## 내장 장치 표시

기본적으로 장치 창은 외장 포인팅 장치(마우스)를 중심으로 표시합니다.

내장 트랙패드도 목록에서 확인하려면 **내장 장치 표시**를 활성화하면 됩니다.

## 설치 방법

1. GitHub Releases 페이지에서 최신 버전을 다운로드합니다.
2. 다운로드한 ZIP 파일의 압축을 해제합니다.
3. **Natural Scrolling Switcher.app**을 `/Applications` 폴더로 이동합니다.
4. 앱을 실행합니다.

NSS는 macOS 메뉴 막대에서 실행됩니다.

## 로그인 시 실행

NSS 메뉴에서 **로그인 시 실행**을 활성화하면 macOS에 로그인할 때 Natural Scrolling Switcher가 자동으로 실행됩니다.

---

## 개인정보 보호

Natural Scrolling Switcher는 사용자의 개인정보를 수집, 저장 또는 전송하지 않습니다.

온라인 계정이 필요하지 않으며 분석 기능이나 텔레메트리를 사용하지 않습니다.

---

## 기술적 참고 사항

macOS는 포인팅 장치마다 서로 다른 시스템 수준의 스크롤 방향을 설정하는 기능을 제공하지 않습니다.

NSS는 현재 적용할 장치 설정에 따라 macOS의 전역 자연스러운 스크롤 값을 동적으로 변경하는 방식으로 이 제한을 우회합니다.

장치 감지는 주기적인 폴링 방식이 아니라 이벤트 기반으로 동작합니다.

## macOS 보안 경고 안내

현재 Natural Scrolling Switcher는 Apple Developer ID로 서명되거나 Apple의 공증(Notarization)을 받은 앱이 아닙니다.

따라서 앱을 처음 실행할 때 macOS가 개발자를 확인할 수 없다는 보안 경고를 표시하고 실행을 차단할 수 있습니다.

이 경우 다음 방법으로 앱을 실행할 수 있습니다.

1. **시스템 설정 → 개인정보 보호 및 보안**을 엽니다.
2. Natural Scrolling Switcher가 차단되었다는 메시지에서 **그래도 열기**를 선택합니다.
3. 이후 표시되는 확인 창에서 다시 **열기**를 선택합니다.

Natural Scrolling Switcher는 개인정보를 수집, 저장 또는 외부 서버로 전송하지 않습니다.
